## v1의 결함 3가지 (모두 수정)

| # | v1 코드 | 문제 | v2 |
|---|---|---|---|
| 1 | `dg = abs(γ(0) − γ(φ))` | "가장자리가 에탄올 0%까지 완전 고갈"이라는 **숨은 가정**. φ에 대해 단조증가 → *"농도↑ → 억제↑"를 결론이 아니라 전제로 넣은 것* | `Δγ = γ((1−f)·x) − γ(x)`. `f` = 고갈 분율 (모델링 선택). **접선 근사 안 씀** — γ 곡선은 φ→0에서 기울기가 −240 mN/m로 발산하므로 접선 근사는 저농도 폭주를 낳는다 |
| 2 | `φ` = 상수 | 에탄올은 물보다 α = 2.5배 빨리 증발해 **건조 중 소진된다**. v1은 이를 무시 | 조성 `x(t)`를 시간 적분. 마랑고니는 전반부만 작동, 후반부는 순수 물 건조 → **잔류 링** 형성 |
| 3 | `φ**1.5` · `theta_factor = h0_ref/h0` | `φ^1.5`는 코드 주석에 목적이 적힌 **튜닝 상수**. `theta_factor`는 스케일링 유도와 **부호·지수 모두 반대** | 제거. 대신 유도: `Ma ∝ Δγ/(μ·J₀) · tan²(θ/2)` |

### 핵심 유도

```
u_mar ~ Δγ·h/(μ·a)        (표면 응력 → 유동)
u_cap ~ J₀·a/(ρ·h)        (Deegan 증발 보충류)
⇒  Ma ≡ u_mar/u_cap  ∝  Δγ/(μ·J₀) · (h/a)²  =  Δγ/(μ·J₀) · tan²(θ/2)
```

접촉각이 **자동으로** 등장한다. 접촉선이 고정된 액적은 마르면서 θ가 계속 줄어들므로
마랑고니가 기하학적으로 약해지고, 마지막엔 모세관이 이겨 **잔류 링**이 생긴다.

## 핵심 결과 — v2는 v1의 예측을 뒤집는다

```
Ma (K = 1 기준):    E30 = 2.77e-3    E50 = 1.35e-3    E70 = 1.06e-3
```

에탄올을 넣으면 액적이 납작해진다 (실측 θ₀ : 41.8° → 26.3°).
`tan²(θ/2)`가 무너지면서 **기하학적 효과가 화학적 효과를 이긴다.**
Δγ는 사실상 평평(≈ 4 mN/m)한데 tan²(θ/2)는 2.6배 감소한다.

> **마랑고니 억제는 에탄올 농도가 높을수록 강해지지 않는다. 오히려 약해진다.**

**그리고 이 결론은 모델링 선택 `f`와 무관하다.** `f = 1`(= v1의 가정)에서도
`Ma(E70)/Ma(E30) = 0.57 < 1`. 지배 인자는 **실측 접촉각**과 **문헌 증기압비**다.

## 파라미터 (전부 공개)

**이론·문헌값 (고정, 튜닝 없음)**
γ(φ) 보간표 (Vazquez et al. 1995) · μ(φ) 혼합 점성 · α = 2.5 (증기압비) · Deegan λ(θ)

**실험 경계조건** (액적 반경 R과 동일 범주의 초기조건)
`a(φ)` 접촉 반경 = 건조 후 얼룩 지름 / 2 · `θ₀(φ)` 초기 접촉각 (측면 사진)

**환경 보정 1개**
`C_evap` ← **E0(순수 물, 마랑고니 없음) 건조 곡선 하나로만 보정.** 실험실 온습도를 읽는 것.
→ E30 / E50 / E70의 건조 곡선은 전부 **예측**이 된다.

**모델링 선택 2개 (민감도 분석 대상)**
`f` 가장자리 고갈 분율 · `K` 마랑고니 전체 세기 스케일

**예측 (검증 대상 — 절대 입력하지 않음)**
θ(t) 4농도 × 3시점 = 12점 · 침착 패턴 (e/c, 반경 밀도) · 최적 농도

## 유효 범위와 한계

| 구간 | 상태 | 이유 |
|---|---|---|
| φ < 25% | ❌ **모델 무효** | γ(φ)가 로그 형태 → Δγ가 φ에 거의 무관 → tan²(θ/2)만 남아 비물리적 중앙 스파이크. 근본 해결은 가장자리 조성의 2D 이류-확산 계산 (본 연구 범위 밖) |
| 25% ≤ φ ≤ 60% | ✅ **유효** | 최적 구간(35~50%)이 이 안에 있다 |
| φ > 60% | ❌ **실험 무효** | 접촉선이 풀린다 (E70 : θ = 6.86° < 후퇴각). 모델은 링을 예측하는데 실측은 균일 — **이 불일치 자체가 depinning의 증거** |

기타 한계
- **건조 곡선 예측이 고농도에서 어긋난다.** θ(15분) 예측 0.5° vs 실측 6.9°. 용질 농축에 의한 증발 억제 미반영. **θ(t) 측정이 이 결함을 잡아냈다.**
- **깊이평균 근사가 마랑고니 순환을 뭉갠다.** 수직 순환 루프가 하나의 알짜 반경 속도로 붕괴한다.
- **Bond 수 ≈ 3~8.** 액적(8~10 mm)이 모세관 길이(물 2.7 mm)를 넘어 중력에 눌린 웅덩이다 → 정량이 아닌 경향 예측.
